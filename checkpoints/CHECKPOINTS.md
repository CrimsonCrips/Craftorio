# Craftorio Checkpoints

A checkpoint is a version logged whenever CrimsonCrips says "checkpoint". Each entry lists what changed since the checkpoint before it. The first checkpoint is compared against the last commit (`44350c2`, "final before 1.3").

- Full diff of each version: `vN.patch` in this folder.
- `checkpoint.sh` makes the patch and updates `.snapshot/` (the saved state used as the starting point for the next one). It never commits anything.
